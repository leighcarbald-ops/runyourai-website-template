# RunYourAI Website Template

Reusable, mobile-first small-business website template designed for fast prospect demos and GitHub Pages deployment.

## Fast customization

For most new demos, edit **only `business.js`**.

Change:
- business name and initials
- phone, email, address, city/state
- brand colors
- headline and call-to-action
- services
- trust points
- about copy
- real public reviews only
- business hours
- optional hero image URL

The rest of the site is automatically populated from that one configuration file.

## Important demo rule

Do not invent customer reviews, ratings, awards, certifications, years in business, prices, or guarantees. Use verified public information, business-provided information, or clearly generic placeholder copy.

## GitHub Pages

The site is plain HTML/CSS/JavaScript and requires no build step, database, Cloudflare Worker, or paid hosting dependency.

To publish a cloned customer/demo repository with GitHub Pages, use the repository's Pages settings and publish from the default branch/root when available for that repository/account configuration.

## Files

- `index.html` — page structure
- `styles.css` — responsive design
- `business.js` — all prospect-specific content and colors
- `script.js` — injects business configuration into the page

## RunYourAI workflow

1. Duplicate this template into a prospect-specific repository.
2. Gather verified public business details.
3. Customize `business.js` for the business and industry.
4. Add an approved/public image if appropriate.
5. Publish the demo through GitHub Pages.
6. Send the prospect the demo link for the scheduled walkthrough.
7. After purchase, confirm final content through onboarding before presenting the site as the customer's official website.
